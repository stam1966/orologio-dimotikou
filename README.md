# Ωρολόγιο Δημοτικού

Εφαρμογή για Windows που φτιάχνει και διορθώνει το ωρολόγιο πρόγραμμα ενός δημοτικού σχολείου, με λειτουργίες ανάλογες του aSc TimeTables. Λειτουργεί τοπικά στον υπολογιστή, χωρίς Internet· τα δεδομένα του σχολείου δεν φεύγουν ποτέ από αυτόν.

## Λήψη

**[⬇ Λήψη της τελευταίας έκδοσης (Setup.exe)](https://github.com/stam1966/orologio-dimotikou/releases/latest/download/Orologio_Dimotikou_Setup.exe)** και ανοίξτε το αρχείο. (Όλες οι εκδόσεις: [Releases](https://github.com/stam1966/orologio-dimotikou/releases).) Δεν χρειάζονται δικαιώματα διαχειριστή. Αν τα Windows δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

## Τι κάνει

- Εισαγωγή από aSc TimeTables (XML) και εξαγωγή πίσω προς το aSc.
- Αυτόματη δημιουργία προγράμματος με κανόνες υποχρεωτικούς ή επιθυμητούς: διαθεσιμότητες ✔/?/✖, ώρες παρουσίας, 5ωρα/4ωρα, συνεχόμενες ώρες, Πρωινή Ζώνη, Ολοήμερο, δίωρα, κοινά μαθήματα.
- Διάγνωση: όταν δεν υπάρχει λύση, δείχνει ποιοι κανόνες συγκρούονται.
- Χειροκίνητες διορθώσεις σε όλη την εβδομάδα με ένα κλικ, αιτιολογία για κάθε θέση που δεν επιτρέπεται, αναίρεση.
- Εκδοχές προγράμματος με σημείωμα αλλαγών ανά εκπαιδευτικό, δικαιοσύνη κατανομής, επίσημο ωρολόγιο ανά τάξη.
- Εκτυπώσεις, αφίσες A3, Excel, ένα PDF ανά εκπαιδευτικό.
- Ενημέρωση μέσα από την εφαρμογή, ημερήσια αντίγραφα ασφαλείας, σημεία επαναφοράς.

## Για προγραμματιστές

- `src/`: εφαρμογή (Python 3.12, OR-Tools CP-SAT, τοπική υπηρεσία + σελίδα HTML).
- `tests/`: αυτόματοι έλεγχοι· `tools/smoke.py`: έλεγχος λειτουργίας σε Windows.
- `tools/build_package.py`: runtime και πακέτα· `installer/orologio.iss`: Setup.exe (Inno Setup).
- Το GitHub Actions ελέγχει κάθε αλλαγή σε Windows με τον πραγματικό solver. Μια ετικέτα `vX.Y.Z` δημοσιεύει έκδοση.

Στο αποθετήριο δεν αποθηκεύονται ποτέ δεδομένα σχολείου (ο φάκελος `data/` εξαιρείται).
