# Ωρολόγιο Σχολείου

*Ιδέα και σχεδιασμός: Σταμάτης Κοκολόγος, εκπαιδευτικός ΠΕ70, 22ο Δημοτικό Σχολείο Λαμίας.*

[Code signing policy](CODE_SIGNING_POLICY.md) · Άδεια χρήσης: [GPL-3.0](LICENSE)

Εφαρμογή για Windows που φτιάχνει και διορθώνει το ωρολόγιο πρόγραμμα ενός δημοτικού σχολείου, με λειτουργίες ανάλογες του aSc TimeTables. Λειτουργεί τοπικά στον υπολογιστή, χωρίς Internet· τα δεδομένα του σχολείου δεν φεύγουν ποτέ από αυτόν.

## Λήψη

**Ψηφιακή υπογραφή:** οι εκδόσεις δεν έχουν ακόμη ψηφιακή υπογραφή (αν τα Windows δείξουν προειδοποίηση: «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε») — βλ. [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md), όπου και η πολιτική ιδιωτικότητας. Απεγκατάσταση: Ρυθμίσεις των Windows → Εφαρμογές (τα δεδομένα του σχολείου δεν σβήνονται).


**[⬇ Λήψη: Σχολικές Εφαρμογές — Ωρολόγιο + Εφημερίες (Sxolikes_Efarmoges_Setup.exe)](https://github.com/stam1966/orologio-sxoleiou/releases/latest/download/Sxolikes_Efarmoges_Setup.exe)** και ανοίξτε το αρχείο. Εγκαθιστά και τις δύο εφαρμογές (μπορείτε να ξετσεκάρετε όποια δεν θέλετε), ρωτά αν θα χρησιμοποιηθούν και από δεύτερο υπολογιστή (κοινός φάκελος, ρόλος) και δημιουργεί το εικονίδιο «Σχολικές Εφαρμογές», που ανοίγει το παράθυρο επιλογής Ωρολόγιο ή Εφημερίες. Αν έχετε ήδη κάποια από τις δύο εφαρμογές, δεν χρειάζεται απεγκατάσταση. Δεν χρειάζονται δικαιώματα διαχειριστή. Αν τα Windows δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

Μόνο το Ωρολόγιο (χωρίς Εφημερίες και παράθυρο επιλογής): [Orologio_Sxoleiou_Setup.exe](https://github.com/stam1966/orologio-sxoleiou/releases/latest/download/Orologio_Sxoleiou_Setup.exe). Αρχείο ενημέρωσης για υπολογιστή χωρίς Internet (πάντα η τελευταία έκδοση): [Orologio_Enimerosi.zip](https://github.com/stam1966/orologio-sxoleiou/releases/latest/download/Orologio_Enimerosi.zip). Όλες οι εκδόσεις: [Releases](https://github.com/stam1966/orologio-sxoleiou/releases).

## Τι κάνει

- Εισαγωγή από aSc TimeTables (XML) και εξαγωγή πίσω προς το aSc.
- Αυτόματη δημιουργία προγράμματος με κανόνες υποχρεωτικούς ή επιθυμητούς: διαθεσιμότητες ✔/?/✖, ώρες παρουσίας, 5ωρα/4ωρα, συνεχόμενες ώρες, Πρωινή Ζώνη, Ολοήμερο, δίωρα, κοινά μαθήματα.
- Διάγνωση: όταν δεν υπάρχει λύση, δείχνει ποιοι κανόνες συγκρούονται.
- Χειροκίνητες διορθώσεις σε όλη την εβδομάδα με ένα κλικ, αιτιολογία για κάθε θέση που δεν επιτρέπεται, αναίρεση.
- Εκδοχές προγράμματος με σημείωμα αλλαγών ανά εκπαιδευτικό, δικαιοσύνη κατανομής, επίσημο ωρολόγιο ανά τάξη.
- Εκτυπώσεις, αφίσες A3, Excel, ένα PDF ανά εκπαιδευτικό.
- Έντυπα Διεύθυνσης σε Excel (Ω.Π. και διδακτικό ωράριο, Ολοήμερο), προϋπολογισμός αναγκών ανά κλάδο, Ε.Δ.Υ./βιβλιοθήκη/ενισχυτική, ημέρα εφημερίας από την εφαρμογή «Εφημερίες».
- Ενημέρωση μέσα από την εφαρμογή, ημερήσια αντίγραφα ασφαλείας, σημεία επαναφοράς.

## Για προγραμματιστές

- `src/`: εφαρμογή (Python 3.12, OR-Tools CP-SAT, τοπική υπηρεσία + σελίδα HTML).
- `tests/`: αυτόματοι έλεγχοι· `tools/smoke.py`: έλεγχος λειτουργίας σε Windows.
- `tools/build_package.py`: runtime και πακέτα· `installer/orologio.iss`: Setup.exe (Inno Setup).
- Το GitHub Actions ελέγχει κάθε αλλαγή σε Windows με τον πραγματικό solver. Μια ετικέτα `vX.Y.Z` δημοσιεύει έκδοση.

Στο αποθετήριο δεν αποθηκεύονται ποτέ δεδομένα σχολείου (ο φάκελος `data/` εξαιρείται).
